# Java Chart Editor

Welcome to the final version of the **Java Chart Editor**! This repository marks the mature, stable milestone of the Java-based iteration of the editor before transitioning the core development over to Rust.

## Project Status

- **Current Version:** Final Java Release
- **Maintenance:** Active for bug fixes only.
- **New Features:** No new features will be added to this codebase.

## What's Next?

The project is moving forward! A brand new, high-performance **Rust Chart Editor** is coming soon. Stay tuned for a faster, more powerful rewrite built from the ground up.
